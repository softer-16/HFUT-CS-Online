# 数据结构模拟器来源

作者为 Cynthia Wang，来源为 https://github.com/softer-16/data-structure-simulator ，导入版本为 c27381eae22d806e4e17a16b32311e9ad4cc369e。

共 69 个演示，保留参数输入、步骤轨迹、变量状态和知识点。
运行时在 React 课程组件的 ShadowRoot 中挂载，样式继承本站主题令牌。
所有脚本和样式随本站构建，路由卸载时停止计时器。
支持 /ds/<algorithmId> 直接进入指定主题。
当前共享代码映射保留在源元数据中待后续校对，展示只采用同名代码。
其余主题展示真实的 JavaScript 步骤生成代码，并显式标注。
